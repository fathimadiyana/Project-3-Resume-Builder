
# Resume Builder —  Week 2 Project 3

## Run
Open `Resume_Builder.html` directly in Chrome or Edge. No installation, login, internet, paid API or server is needed.

## Features
- Form fields for contact details, profile, skills, education, experience, projects, certifications and languages
- Live A4 resume preview
- Three different templates and selectable accent colour
- Drag-and-drop section reordering
- Save resume data to JSON and load it back
- Export through browser Print → Save as PDF; text remains selectable
- Responsive editor and preview

## PDF export
Click Export PDF or Print / Save PDF. In the print dialog choose "Save as PDF", paper size A4, and disable browser headers/footers if desired. The PDF uses selectable text because the resume is rendered as HTML text, not a screenshot.

## Notes
This is a local browser app. Resume details are not uploaded. The sample data is fictional/demo content; replace it with accurate information before use. A long resume should flow onto additional A4 pages through browser printing; inspect page breaks in print preview.
